Description
A CRUD-based Notes Application built with React that enables users to create, edit, update, and delete notes. Data persistence is achieved through LocalStorage, ensuring notes remain available between sessions.

Live Demo
🔗 Live: https://mohammad-aahil.github.io/notes-app

Source Code
💻 GitHub: https://github.com/Mohammad-Aahil/notes-app

Features
* Create notes
* Edit existing notes
* Delete notes
* Update notes in real time
* LocalStorage integration
* Persistent data storage
* Responsive interface

Technologies Used
* React.js
* JavaScript (ES6+)
* LocalStorage
* CSS
* Vite
